Bot is a companion to the user's existing web app (AFTL guild raid planner). Primary feature: ping Discord roles based on what a raid lineup needs. The user already has a Discord application used for OAuth login in the web app — the bot is being added to that same application.

**Why:** The guild needs a way to notify members via Discord when raid lineups have open slots for specific roles.
**How to apply:** Features should focus on raid planning workflows — role pinging, lineup notifications, etc.
